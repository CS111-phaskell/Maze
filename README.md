The repository contains files used in a Maze Solver program made using Java.

In the 'maze' folder, there are 12 different text files that are mazes used to test the maze solver.
Mazes 1 - 8 test possible errors in maze input files. The maze number corresponds with the possible errors in the PossibleErrors.txt
Mazes 9 - 12 are mazes with different "difficulties", starting with maze 9 being the "easy" maze and ending with maze 12 being the "very hard" maze.

There are two files that solve the maze: MazeSolver.java and MazeSolver1.java

MazeSolver.java reads the maze text file and stores it into a two dimensional array.

MazeSolver1.java contains the actual algorithim used to solve the maze. 

The comments.txt file is blank, please disregard this.
